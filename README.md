# Curso de Análisis de Algoritmos

Repositorio correspondiente al curso de Análisis de Algoritmos. En este repositorio se almacenarán los ejercicios de clase, laboratorios evaluativos y scripts utilizados para realizar mediciones de rendimiento.

## Objetivo

El objetivo de este repositorio es organizar y versionar el trabajo realizado durante el semestre, aplicando buenas prácticas de Git y GitHub y documentando los diferentes ejercicios y experimentos realizados en el curso.

## Estructura del repositorio

- `laboratorios/`: contiene los informes y entregas correspondientes a los cinco laboratorios evaluativos del curso.
- `ejercicios-clase/`: contiene los ejercicios prácticos realizados durante las sesiones de clase.
- `benchmarks/`: contiene scripts utilizados para medir tiempos de ejecución y generar gráficas para analizar el rendimiento de los algoritmos.

A continuación se presenta un ejemplo sencillo de una función en Python:

def suma(a, b):
    return a + b

resultado = suma(5, 3)

## Control de versiones

El proyecto utiliza Git para realizar el seguimiento de los cambios y GitHub como repositorio remoto.
